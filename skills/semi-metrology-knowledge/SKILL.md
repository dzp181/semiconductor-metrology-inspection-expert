# 半导体量测检测设备知识底座

本 skill 是 `semiconductor-metrology-inspection-expert` 的参考资料层。**回答涉及具体设备原理、参数窗口、厂商份额、供应链映射之前，先读对应 reference，不要凭记忆报数字。**

## 何时加载

- 用户问某类量检测设备（OCD / CD-SEM / Overlay / 膜厚 / 无图形检测 / 图形检测 / EBI / X-ray / 封装 AOI）的原理、优劣、适用场景
- 用户要做设备选型、参数对标、或问"某指标多少算够"
- 用户要梳理量检测产业链、国产替代进度、核心标的与上游零部件
- 用户要做良率爬坡 / 缺陷归因 / 过程控制方案
- 用户要一份可交付的量检测评审报告或产业研究框架

## 使用规则

1. **先查后答**：涉及具体原理、参数、份额时先读对应 reference；reference 里没有的，明确说"无公开可靠口径"，给获取方法而不是编数字。
2. **三档数据标注**：所有数字必须标明【公开事实】/【工程经验区间】/【研判推测】，推测不得伪装成数据。
3. **概念先纠偏**：用户若把量测说成检测（或反之），先纠正再回答，不要顺着错误前提往下走。
4. **份额必带口径**：厂商份额一律写"年份 + 统计口径（前道 WFE / 量检测细分 / 全球或中国）"，不同口径差异极大。
5. **国产三阶段**：讨论国产厂商时严格区分「技术发布 / 首台验证 / 批量重复订单」，禁止把发布等同于量产。
6. **不越界**：不提供规避出口管制、逆向工程、绕开专利的具体方法；不构成投资建议。
