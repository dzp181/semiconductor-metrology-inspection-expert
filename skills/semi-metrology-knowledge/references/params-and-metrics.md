# 关键参数与指标口径（Params & Metrics）

> 用途：参数对标、"多少算够"、选型评审。**本文件所有数值均为"典型量级 / 工程经验区间"，不是规格书；报价或验收必须以厂商 datasheet 与双方 spec 为准。**

## 1. 先分清三类指标，否则没法比

| 类别 | 指标 | 含义 | 谁在意 |
|---|---|---|---|
| 能力指标 | 分辨率、灵敏度、可测范围 | 物理上"能不能测" | 工艺整合、研发 |
| 质量指标 | 精度、重复性、匹配性、准确性 | 测出来"准不准、稳不稳" | 量测工程师、APC |
| 经济指标 | 吞吐、uptime、CoO、占地面积 | 用起来"划不划算" | 采购、产能规划 |

> 常见误区：只比分辨率和灵敏度。产线上真正决定设备能否留下的，往往是**重复性 + 匹配性 + 误报率**。

## 2. 指标定义与量级参考

### 2.1 精度与重复性
- **重复性（Precision / TMU）**：同一片、同一位置重复测量的分布（动态重复性含上片/寻址误差）。先进节点关键层通常要求重复性达到**被测尺寸的百分之几甚至更低**量级。
- **准确性（Accuracy / Bias）**：与参考量测（CD-SEM、TEM、XRD、标准片）的偏差，靠标准片溯源与交叉标定控制。
- **Tool-to-tool matching**：同型号多台设备读数一致性。Fab 里同一层常有 5–30 台设备，匹配性差 → 无法共用 recipe 与 APC 模型。
- **长期稳定性**：热漂移、光源老化、探测器衰减带来的漂移，决定校准频次。

### 2.2 缺陷检测类
| 指标 | 含义 | 备注 |
|---|---|---|
| 灵敏度（Sensitivity） | 能稳定抓到的最小缺陷尺寸 | 与吞吐强 trade-off，同一台机"高灵敏模式"吞吐骤降 |
| 捕获率（Capture Rate） | 实际抓到已知缺陷的比例 | 用标准缺陷片（programmed defect wafer）评估 |
| 误报率 / Nuisance | 报出的假缺陷占比 | **国产设备进线的头号杀手**，比灵敏度更影响口碑 |
| 缺陷分类准确率 | ADC 分类正确比例 | 先进节点要求高，靠缺陷库训练 |
| 吞吐（wph） | 每小时晶圆数 | 强烈依赖 recipe 与检测面积 |

> 经验：Fab 评估新检测设备时，通常先跑"已知缺陷片 + 真实产线片"双盲对比，看**捕获率 vs 误报率曲线**，而不是单点灵敏度。

### 2.3 套刻（Overlay）
- 指标分为：TMU（量测不确定度）、残差（residual）、匹配性。
- 量级参考：成熟节点套刻预算十 nm 级；先进节点进入 **2nm 以内**（含残差）量级，量测本身的不确定度必须显著小于预算。
- **关键**：套刻量测的不确定度会直接吃掉可分配的光刻预算，因此先进节点对 DBO 与 in-die 量测的需求上升。

### 2.4 膜厚与光学量测
- 椭偏厚度精度可到**亚埃级**（超薄膜，理想条件），实际产线受光学常数漂移、表面粗糙度影响。
- 多层膜拟合的可靠性取决于模型层数与材料库，**模型错 → 系统性偏差**，这是膜厚量测最常见的坑。
- XRR 适合超薄膜与界面，但速度慢、对表面污染敏感。

### 2.5 经济与运营指标
| 指标 | 说明 |
|---|---|
| 吞吐 | wph；量检测是"不产出的成本"，吞吐直接换算成机台数量 |
| Uptime / MTBF | Fab 24×7，可用率差 1% 就是产能问题 |
| CoO（Cost of Ownership） | 含耗材、备件、校准片、人力、占地 |
| 服务响应 | 备件库与驻厂工程师，是海外龙头长期优势，也是国产可反超的点 |
| 洁净与占地 | 量检测设备常在洁净室黄金位置，footprint 是隐性成本 |

## 3. 工艺节点 → 指标要求（定性映射，非规格）

| 节点/场景 | 量测特征 | 检测特征 |
|---|---|---|
| ≥28nm 成熟 | 量测点较少，膜厚+CD 为主 | 光学检测足够，EBI 少 |
| 14/7nm | OCD 与 CD-SEM 密度上升，套刻要求收紧 | 光学图形检测灵敏度提升，复查量增加 |
| 5/3nm（FinFET/GAA、EUV 多重图形） | 3D 结构量测、in-die 套刻、OCD 模型复杂化 | 亚 10nm 缺陷灵敏度，EBI 用量上升，缺陷分类靠 AI |
| 2nm 及以下（High-NA EUV、背面供电） | 背面/埋层量测、更多量测点、计算量测与虚拟量测 | 多束 EBI、混合检测（光学+电子束） |
| 先进封装（CoWoS/HBM/混合键合） | 翘曲、共面度、键合对准、TSV 形貌 | X-ray/CT、SAT、红外、AOI，自动化程度低、人工多 |
| 3D NAND | 超高深宽比沟道孔 OCD + 剖面 SEM | 深孔缺陷、堵塞、弯曲检测 |

## 4. 选型评审的七个必问

1. 这台设备要解决的是**研发线问题**还是**量产线问题**？（决定验收标准）
2. 关键指标是**重复性/匹配性**还是**灵敏度**？Fab 里谁签字？（决定权重）
3. 误报率在真实产线片上能压到多少？有没有 nuisance 抑制手段？
4. recipe 迁移成本多大？能不能对接现有 YMS/APC？
5. 与参考量测（CD-SEM/TEM）的交叉标定方案是什么？
6. 服务：备件库在哪、响应时间、驻厂人数、软件升级策略？
7. CoO 五年算下来和竞品差多少？（含耗材与校准片）

## 5. 常见数据陷阱

- "分辨率" 与 "可测最小尺寸" 不是一回事；
- "灵敏度" 常在不说明吞吐的前提下给出，实际产线跑不到；
- 份额数据必须区分**全球/中国**、**前道 WFE/量检测细分**、**金额/台数**；
- 国产"首台交付" ≠ 批量重复订单，两者估值含义完全不同；
- 量检测设备的单价跨度极大（从百万级到上亿级人民币），谈"均价"没有意义，必须按品类。
