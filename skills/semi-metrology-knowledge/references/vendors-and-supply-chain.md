# 厂商格局与供应链卡点（Vendors & Supply Chain）

> 用途：产业链梳理、标的定位、卡点判断。**份额、营收、客户名单高度时效敏感，一律标注"需以公司公告/第三方机构最新报告核验"，不得当作硬数据引用。**

## 1. 产业链分层

```
上游：零部件与材料
├── 精密光学：深紫外/宽谱光源、高NA物镜、大口径镜片、镀膜、衍射光学元件
├── 精密机械：纳米级运动台、减振平台、精密导轨、超精密加工件
├── 电子光学：场发射电子枪、镜筒、探测器（SEM/EBI 核心）
├── 电子与数据：高速采集卡、图像处理、激光器、传感器
└── 材料：标准片/校准片、靶材、特种气体（封装检测用）

中游：量检测设备整机
├── 前道量测：OCD、CD-SEM、Overlay、膜厚、AFM、X-ray
├── 前道检测：无图形、图形、EBI、Macro、掩模检测
├── 封装检测：AOI、X-ray/CT、SAT、红外、白光干涉
└── 软件：ADC/YMS/APC/虚拟量测

下游：晶圆厂与封测厂
├── 逻辑代工（先进节点量测密度最高）
├── 存储（3D NAND / DRAM / HBM）
├── 封测与先进封装（CoWoS、混合键合）
└── 功率/模拟/特色工艺（成熟节点，量大但单机要求低）
```

## 4. 国产替代难度阶梯

```
① 无图形表面检测        ████████░░  已批量进线
② 膜厚/形貌/三维量测     ██████░░░░  部分量产，成熟节点为主
③ 图形晶圆缺陷检测       ████░░░░░░  单点突破，先进节点验证中
④ OCD / 套刻量测         ███░░░░░░░  验证期，模型与 recipe 是短板
⑤ 电子束检测/复查        ██░░░░░░░░  早期，镜筒与电子枪受制
⑥ EUV 掩模版检测         ░░░░░░░░░░  基本空白，Lasertec 垄断
```

判断替代进度时必问三件事：
1. 进的是**研发线**还是**量产线**（量产线才有重复订单）；
2. 覆盖的是**成熟节点**还是**先进节点**（先进节点验证周期长得多）；
3. 客户是**单点试用**还是**同一层多台复制**（多台复制才是真验证通过）。

## 5. 卡点逐层拆解

| 层级 | 卡点 | 难度 | 说明 |
|---|---|---|---|
| 光学 | 深紫外/宽谱光源、高 NA 物镜、超低缺陷镀膜、大口径镜片加工与检测 | 高 | 决定分辨率与灵敏度上限，国产镜片一致性与寿命是主要差距 |
| 机械 | 纳米级运动台、减振、热稳定 | 高 | 精度直接受热漂移限制，量测设备对温度控制的要求比工艺设备更苛刻 |
| 电子光学 | 高亮度场发射电子枪、镜筒像差校正、低电压高分辨 | 很高 | EBI 的核心，国产差距最大的一环 |
| 数据与算法 | 高速采集、实时图像处理、缺陷分类模型、缺陷库积累 | 中高 | 硬件可买，数据要一片片积累，是最难"跳步"的部分 |
| 生态 | recipe 迁移成本、YMS/APC 集成、客户对误报的容忍度 | 高 | 决定"进了线能不能留下来" |
| 服务 | 备件库、驻厂工程师、响应时效 | 中 | 国产的相对优势项，可主动打这张牌 |

## 6. 投资/研究跟踪清单

**产业侧**
- 头部代工厂与存储厂的资本开支指引（决定量检测订单大盘）
- 先进封装（CoWoS/HBM）扩产节奏（决定封装检测弹性）
- 国产设备招标中标记录（比发布会可靠得多）

**公司侧**
- 量检测收入占比、单一客户集中度
- 首台→重复订单的转化周期
- 毛利率与服务收入占比（软件与服务占比高 = 质量好）
- 研发费用率与专利结构（光学/电子光学/算法三类分布）

**风险侧**
- 海外龙头降价封堵
- 下游扩产周期下行
- 验证不通过导致的收入确认延后
- 出口管制导致的零部件断供（光学、电子枪、高端芯片）

## 7. 口径提醒

- 份额：必须写清"全球/中国"、"前道 WFE/量检测细分"、"金额/台数"、"哪一年"。
- KLA 的"半壁江山"指的是**量检测细分**，不是整个半导体设备市场。
- 量检测占设备投资的比例，不同机构给 8%–13% 不等，取决于是否含封装检测、是否含服务。
- 所有国产厂商的"突破"新闻，默认按「技术发布 < 首台验证 < 批量订单」三档降级理解。
