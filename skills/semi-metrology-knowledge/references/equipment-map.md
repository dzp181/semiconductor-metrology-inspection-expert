# 量检测设备图谱（Equipment Map）

> 用途：原理问答、设备选型对比、概念纠偏。凡以下未列出的机型细节、最新代际，标注"需以厂商最新资料核验"。

## 1. 尺寸类量测

### OCD / 散射测量（Optical CD, Scatterometry）
- **原理**：宽谱光（或特定波长组合）斜入射到周期性结构，采集反射/衍射谱，用 RCWA 等电磁模型反演 CD、侧壁角（SWA）、深度、膜厚、甚至 3D 形貌。
- **优势**：非破坏、高通量、可测高深宽比与 3D 结构（GAA、3D NAND 沟道孔），是先进节点量测点数增长最快的品类。
- **局限**：依赖模型与 recipe，模型不准 → 系统偏差；对非周期/孤立结构不友好；新材料光学常数变化需重新标定。
- **关键难点**：模型库建设、与参考量测（CD-SEM/TEM/XRD）的交叉标定、机器学习补偿。
- **主要厂商**：KLA、Nova、ASML（YieldStar）、上海精测（精测电子）。

### CD-SEM（临界尺寸扫描电镜）
- **原理**：聚焦电子束扫描，二次电子成像，直接测线宽/孔径/侧壁。
- **优势**：直观、精度高、可做形貌判断；是 OCD 模型的"锚"。
- **局限**：速度慢、charging/收缩效应（光刻胶尤为明显）、样品制备敏感；高深宽比底部成像困难。
- **主要厂商**：Hitachi High-Tech（长期主导）、Applied Materials。

### AFM / 台阶仪
- **AFM**：纳米级三维形貌，适合测粗糙度、栅极形貌、新型材料；慢、针尖易损。代表：Park Systems、Bruker、Oxford Instruments。
- **台阶仪（Profilometry）**：测台阶高度/膜厚，简单快速，精度低于 AFM；多用于研发与封装。

## 2. 套刻量测（Overlay）

- **测什么**：当前层图形相对前一层的位置偏差（X/Y 平移、旋转、放大、非线性残差）。
- **两条路线**：
  - **IBO（成像法）**：光学显微镜成像专用套刻标记，直观、对工艺变化鲁棒，但受分辨率限制。
  - **DBO（衍射法）**：基于衍射信号反演，精度更高、标记更小，适合先进节点与 in-die 量测。
- **量级参考**：成熟节点套刻预算在十几 nm 级；先进节点要求进入 **2nm 以内**量级（含残差），是光刻与量测共同的压力来源。
- **与光刻的关系**：套刻误差直接吃掉光刻工艺窗口，先进节点常把套刻测量频次提升到"每片/每场"级别。
- **主要厂商**：KLA、ASML（YieldStar 系列）。

## 3. 薄膜与材料量测

| 手段 | 测什么 | 特点 | 代表厂商 |
|---|---|---|---|
| 椭偏（Ellipsometry，含光谱椭偏） | 厚度 + 光学常数（n/k） | 精度高，适合超薄膜与多层拟合 | Onto、Nova、KLA、睿励 |
| 反射光谱（Reflectometry） | 多层膜厚 | 快、便宜，产线主流 | Onto、KLA |
| XRR（X 射线反射） | 超薄膜厚、界面粗糙度 | 非破坏、精度高、慢 | Bruker、Jordan Valley |
| XRF / TXRF | 金属膜厚、成分、痕量污染 | 元素特异性强 | Bruker、Rigaku、埃芯（X-ray 路线） |
| 四探针 / 涡流 | 方阻、金属膜厚（间接） | 快、便宜，用于监控 | 多家 |
| Raman | 应力、晶相 | 先进节点应力工程必备 | 多家 |
| SIMS / SRP | 掺杂剖面 | 破坏性、离线 | 多家 |

> 说明：X-ray 类量测（XRR/XRF/XRD/CD-SAXS）在先进逻辑与 HBM 场景增长快，是国产可以差异化切入的方向之一。

## 4. 缺陷检测（Inspection）

### 4.1 无图形晶圆表面检测（Unpatterned）
- **原理**：激光斜入射 + 暗场散射收集，颗粒/划伤/雾度按散射光强与角度分类；可配明场做表面形貌。
- **地位**：所有 Fab 的"进厂体检"与设备/耗材监控手段，也是**国产最早实现批量进线**的量检测品类。
- **难点**：亚 20nm 颗粒灵敏度、雾度（haze）与缺陷的区分、高速全片扫描的运动控制。
- **代表**：KLA（Surfscan 系列）、中科飞测、Hitachi。

### 4.2 图形晶圆光学检测（Patterned）
- **原理**：明场/暗场宽谱成像，die-to-die 或 die-to-database 比对，找图形缺失、残留、桥连、断线、颗粒。
- **地位**：量检测市场中**最大、门槛最高**的一块，KLA 接近垄断；先进节点还要叠加"计算检测"（用设计版图与光学模型预测热点）。
- **难点**：光学分辨率与吞吐的矛盾、多模式（明场/暗场/DUV 波长组合）、误报抑制（nuisance suppression）、缺陷分类模型。
- **国产**：中科飞测已有图形检测产品，处于"技术突破 → 批量验证"推进阶段，具体进线规模需以公告核验。

### 4.3 电子束检测（EBI）
- **原理**：SEM 成像 + 电压对比（Voltage Contrast）或形貌比对，抓电性缺陷（通孔未开、断线、短路），灵敏度远超光学。
- **局限**：极慢（相对光学低 2–4 个数量级），只能抽检；charging 与表面污染风险。
- **趋势**：先进节点与 GAA/背面供电推动 EBI 用量上升；多束（multi-beam）是提吞吐的方向。
- **代表**：ASML（HMI eScan/eP 系列）、Applied Materials、东方晶源（国产电子束检测/复查）。

### 4.4 缺陷复查与分析
- **Review-SEM**：把光学检测报出的缺陷坐标逐一放大复查，判定类型；与 EDS 联用做成分分析。
- **失效分析（FA）**：FIB/SEM、TEM 切片，属实验室能力而非产线设备。
- **代表**：Applied Materials（SEMVision）、Hitachi、Thermo Fisher。

### 4.5 掩模版检测
- **测什么**：掩模图形缺陷、EUV 掩模基板（blank）缺陷、pellicle 检查。
- **格局**：**Lasertec 在 EUV 掩模/blank 检测上接近独家**，是全行业最硬的单点垄断之一；国产基本空白。
- **为什么重要**：一个掩模缺陷会被重复曝光到成千上万片晶圆上。

### 4.6 先进封装与存储专用检测
| 场景 | 手段 | 关注缺陷 |
|---|---|---|
| 焊点/凸块（bump） | X-ray / 3D CT、AOI | 空洞、偏移、冷焊、桥连 |
| TSV | 红外显微、X-ray、截面 SEM | 空洞、侧壁粗糙、填充不足 |
| 混合键合（Hybrid Bonding） | 红外对准量测、白光干涉（翘曲/共面度）、SAT | 对准偏差、界面空洞、颗粒 |
| 分层/脱层 | 超声 SAT（C-SAM） | 界面分层、delamination |
| 翘曲/共面度 | 白光干涉、激光扫描 | warpage、TTV、bow |
| 3D NAND 沟道孔 | OCD + 剖面 SEM + 光学检测 | 深度不足、弯曲、堵塞 |
| HBM 堆叠 | 红外/超声 + 键合对准 + 最终测试 | 层间偏移、微凸块缺陷 |

- **代表厂商**：Camtek、Onto Innovation、ASMPT（AOI）、Nordson（X-ray）、赛腾股份（Optima）、中科飞测。

## 5. 软件与算法层（最容易被忽视的护城河）

| 模块 | 作用 | 为什么关键 |
|---|---|---|
| ADC（自动缺陷分类） | 用模型把缺陷自动归类 | 决定误报率，直接影响工程师是否愿意开检测 |
| YMS（良率管理） | 缺陷/量测/电性数据关联分析 | Fab 决策入口，绑定客户 |
| APC / R2R | 用测量结果闭环调工艺 | 量测设备进闭环才有真正粘性 |
| 虚拟量测（VM）/ 计算量测 | 用模型预测未测点 | 降低量测成本，先进节点刚需 |
| 数字孪生 / 工艺仿真 | 预测工艺窗口 | 与 EDA/TCAD 交界 |

> 判断一家量检测公司竞争力时，硬件指标只是入场券，**软件与 recipe 生态**决定它能不能长期留在产线上。
